# Shop-DryFruits

Kishmish shop website.

- `index.html` – public page
- `admin.html` – owner page (open `/admin.html`) to change photos and prices
- `products.json` – product list, edited by admin.html
- `images/` – photos

Set the shop name and WhatsApp number (country code + number, e.g. 919876543210) in `products.json`.
